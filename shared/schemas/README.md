# Shared schemas

JSON Schema stubs for the fact-log envelope, ExecutionIntent, Verdict, and the Group A account profile. An intent group is `A` or `B`. An account profile in this contract is group `A` only; the Group A store enforces that.

Normative fields: [15-persistent-schemas-constitution.md](../../docs/design/group_a/15-persistent-schemas-constitution.md).
